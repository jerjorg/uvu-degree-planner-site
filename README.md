# UVU Degree Planner, the page

The built page of the UVU Degree Planner, served at
<https://jerjorg.github.io/uvu-degree-planner-site/>. Lay out your degree
term by term around what you have already passed, then take the plan to
your academic advisor before you register.

What you enter stays in your browser: the page makes no network calls
beyond loading its own files. The page's source and the data it is built
from are kept in a private repository; this one holds the page alone and
is replaced whole on each build.
